# Kalkulačka klientských otázek

Finanční kalkulačka pro klienty (kolik odkládat, kolik budu mít, renta, inflace, spořicí účet, splátka úvěru).
Celá aplikace je jeden soubor `index.html` – bez serveru, bez závislostí.

## Zveřejnění zdarma přes GitHub Pages

1. Repozitář → **Settings → Pages**
2. *Source*: **Deploy from a branch**, branch `main`, složka `/ (root)` → **Save**
3. Za 1–2 minuty bude stránka na `https://esotericgrizzly.github.io/kalkulacka-finance-odpovedi/`

> GitHub Pages pro **soukromý** repozitář vyžaduje GitHub Pro. Na bezplatném účtu je potřeba repozitář přepnout na veřejný
> (Settings → General → Danger Zone → Change visibility).

Nová verze = nahradit `index.html` a pushnout na `main`.
